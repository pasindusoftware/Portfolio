# 🚀 Pasindu Tharuka – Developer Portfolio

A modern, responsive, and minimal portfolio website built to showcase my software engineering projects, technical skills, and professional services.

Live Website: [Pasindu Tharuka Portfolio](https://pasindusoftware.github.io/Portfolio/)

---

## ✨ Features

* **Dynamic Typewriter Effect:** Custom animated header cycling through key titles and specializations.
* **Responsive Layout:** Fully optimized for desktop, tablet, and mobile displays using Tailwind CSS.
* **Dark / Light Mode Toggle:** Seamless theme switching with local storage persistence and system preference detection.
* **Service Showcase:** Highlights expertise in UI/UX Design, Frontend Development, Desktop Applications, Mobile Apps, and POS Systems.
* **Featured Projects Section:** Showcases key production and open-source applications with live links and repository references.
* **Interactive Contact Form:** Built-in section for project inquiries and client communication.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS
* **Reactivity & Logic:** Alpine.js, Vanilla JavaScript
* **Icons & Visuals:** Inline SVG Icons
* **Deployment:** GitHub Pages
